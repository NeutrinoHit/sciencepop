# sciencepop

Научно-популярные материалы NeutrinoHit.

Публикация настроена через GitHub Actions: push в `main` обновляет ветку `gh-pages` статическим HTML-сайтом.

## Опубликовано

- [Телескоп подо льдом: Вселенная глазами нейтрино](neutrino-telescope-astrofest-2026/)

## Политика публикации

Публично публикуются HTML-версии материалов и необходимые ассеты.
Исходные Keynote/PPTX/PDF/ZIP файлы остаются локальными и исключены из git.
